These are existing manuscript figures. Each case JSON records the exact HMI record, SP observation, original input checksums, zoom box and display limits. Scientific observation times are retained for source identification.

Large full-disk input FITS and reconstructed NPZ arrays are not distributed in the current tree. Use the [full-disk workflow](../../full-disk/README.md) to download inputs, perform patch inference, assemble and fill the map, and plot the result. Original research outputs remain in the author's local archive.
